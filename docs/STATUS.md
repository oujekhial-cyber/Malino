# وضعیت پروژه خرج‌یار

سند مرجع برای ادامه کار. آخرین به‌روزرسانی: شهریور ۱۴۰۵.

## یک نگاه کلی

برنامه مدیریت مالی شخصی فارسی، کاملاً آفلاین. تراکنش‌ها را هم از پیامک بانکی
تشخیص می‌دهد و هم دستی/با جمله فارسی ثبت می‌کند.

| مورد | مقدار |
|---|---|
| زبان | Kotlin ۲.۰.۲۰ — صددرصد (هیچ فایل جاوا ندارد) |
| رابط کاربری | Jetpack Compose |
| حجم کد | ۷۸ فایل، حدود ۱۴٬۰۰۰ خط |
| تست‌ها | ۱۵۶ تست واحد، همه سبز |
| حجم APK | نسخه انتشار ۱۰.۴ مگابایت |
| کمینه اندروید | ۱۲ (minSdk 31) |

## قواعدی که نباید شکسته شوند

۱. **بدون اینترنت.** برنامه مجوز `INTERNET` ندارد و نباید بگیرد. همه پردازش‌ها
   روی خود گوشی است. تست `PrivacyGuardTest` نگهبان این قاعده است.

۲. **بدون مجوز میکروفون.** ورودی صوتی از برنامه سیستمی اندروید استفاده می‌کند.

۳. **چیدمان ویجت فقط با نماهای مجاز RemoteViews.** تگ `View` خام پشتیبانی
   نمی‌شود و باعث خطای «can't load widget» می‌شود. تست `WidgetLayoutSafetyTest`
   این را بررسی می‌کند.

۴. **ساخت محلی ممکن نیست.** در محیط توسعه فعلی نه JDK هست نه دسترسی شبکه به
   مخازن Gradle. تنها راه تأیید، GitHub Actions است.

## معماری

```
core/
  balance/    محاسبه مانده برآوردی حساب
  backup/     بکاپ رمزنگاری‌شده (AES-GCM) و بدون رمز
  date/       تقویم جلالی
  money/      ریال/تومان
  nlp/        تحلیل جمله فارسی برای ثبت سریع
  security/   کلید دیتابیس در Android Keystore
  sms/        طبقه‌بندی و استخراج از پیامک بانکی
  text/       ارقام فارسی
data/         Room (رمزنگاری‌شده با SQLCipher) + DataStore
ui/           صفحات Compose، تم‌ها، اجزای مشترک
widget/       ویجت صفحه اصلی با RemoteViews خالص
work/         WorkManager برای پردازش پیامک
```

## قابلیت‌های اصلی

**تشخیص خودکار از پیامک بانکی** — طبقه‌بندی، استخراج مبلغ و تاریخ، تطبیق حساب،
آموزش قالب برای بانک‌های ناشناس، و علامت‌گذاری فرستنده تبلیغاتی.

**ثبت با جمله فارسی** (`core/nlp`) — «۲۵۰ هزار تومن کیک از سوپرمارکت خریدم با
حساب روزمره» را می‌فهمد. اعداد گفتاری، تاریخ نسبی، جهت از فعل، و حدس دسته.
همیشه کارت تأیید نشان می‌دهد و بدون تأیید کاربر ثبت نمی‌کند.

**ویجت صفحه اصلی** — ساعت زنده با `TextClock`، تاریخ شمسی و میلادی، مقادیر مالی.
با هر تغییر داده خودکار تازه می‌شود (از طریق گوش دادن به Room در `KharjYarApp`).
زنگ نیمه‌شب تاریخ را عوض می‌کند.

**پنج تم** — شکوفه نئون، روشنای روز (تنها تم روشن)، نیلوفر، اقیانوس، طلای شاهانه.
هر کدام تصویر کارت و رنگ نئون مخصوص خود دارد.

**امنیت** — دیتابیس با SQLCipher رمز است و کلیدش در Android Keystore. قفل برنامه
با اثر انگشت. جلوگیری از اسکرین‌شات. حذف کامل لاگ در نسخه انتشار.

## امضا و انتشار

کلید در مخزن نیست. جزئیات کامل در `docs/SIGNING.md`.

نسخه انتشار همیشه امضا می‌شود: اگر Secretهای گیت‌هاب تعریف شده باشند با کلید
اختصاصی، وگرنه با کلید پشتیبان `signing/kharjyar-fallback.p12` (رمزش عمومی است
و فقط برای این است که خروجی همیشه قابل نصب باشد).

برای انتشار واقعی، چهار Secret زیر را در گیت‌هاب بسازید:
`KEYSTORE_B64`، `KEYSTORE_PASSWORD`، `KEY_ALIAS`، `KEY_PASSWORD`.

## گردش کار ساخت

هر push به شاخه، این مراحل را اجرا می‌کند و نتیجه را در `dist/` می‌گذارد:

- تست واحد → `dist/build-report.md`
- ساخت debug و release → `dist/KharjYar-{debug,release}.apk`
- خطاهای کامپایل → `dist/compile-errors.log`

اگر خروجی انتشار امضا نشده باشد، گردش کار عمداً شکست می‌خورد.

- پشتیبانی از چند ارز
