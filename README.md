# خرج‌یار (KharjYar)

اپلیکیشن اندرویدی شخصی مدیریت درآمد و مخارج روزمره — کاملاً آفلاین، فارسی و راست‌به‌چپ.

این پروژه بازنویسی کامل «مالینو» با فناوری بومی اندروید است:
**Kotlin + Jetpack Compose + Material 3 + Room + WorkManager + DataStore + Glance**

## قابلیت‌ها

- دریافت پیامک بانکی جدید (با مجوز صریح کاربر) و تفکیک پیامک مالی از غیرمالی
- استخراج مبلغ، مانده، جهت، شناسه حساب، تاریخ/ساعت و شماره پیگیری از متن پیامک
- یادگیری قالب پیامک: خودکار (heuristic) + آموزش دستی با انتخاب فیلدها از متن نمونه
- تشخیص حساب با ترکیب «سرشماره فرستنده + شناسه داخل متن» (چند حساب با یک سرشماره پشتیبانی می‌شود)
- صف بررسی: حساب ناشناخته، قالب ناشناخته و پیش‌نویس‌های نیازمند تأیید — هیچ‌چیز بی‌صدا ثبت قطعی نمی‌شود
- پرسش «برای چه بود؟» با اعلان قابل‌اقدام (وقتی برنامه بسته است) یا مستقیم داخل برنامه
- ثبت دستی تراکنش بدون نیاز به هیچ مجوزی
- دسته‌بندی قانون‌محور محلی + قوانین قابل ویرایش/غیرفعال‌کردن
- انتقال بین حساب‌های خود کاربر: تطبیق دو سمت، خارج از جمع درآمد/هزینه، وضعیت «انتقال ناقص»
- تقویم شمسی (جلالی) با الگوریتم مرجع jalaali و منطقه زمانی تهران
- پول: ذخیره همیشه به «ریال» با `Long`؛ نمایش ریال/تومان بدون گردکردن مخفی
- گزارش‌ها: روزانه/هفتگی/ماه شمسی/سال شمسی + فیلتر حساب و دسته + نمودار خطی
- خروجی PDF فارسی RTL چندصفحه‌ای، کاملاً آفلاین (StaticLayout برای شکل‌دهی حروف)
- بکاپ و بازیابی محلی رمزنگاری‌شده: AES-256-GCM + PBKDF2-HMAC-SHA256 (210هزار تکرار)
- قفل برنامه با AndroidX Biometric (اثر انگشت/چهره/رمز دستگاه)
- ویجت Glance با تنظیم حریم خصوصی (مخفی‌کردن اعداد وقتی قفل فعال است)
- ۴ پالت دستی (اقیانوس، جنگل، غروب، نیمه‌شب) + رنگ پویا Material You + روشن/تاریک/سیستم
- فونت وزیرمتن (مجوز OFL) به‌صورت آفلاین همراه برنامه

## بازکردن پروژه

1. Android Studio (Koala یا جدیدتر) را باز کنید.
2. `File → Open` و پوشه ریشه مخزن را انتخاب کنید.
3. Gradle sync به‌صورت خودکار وابستگی‌ها را دانلود می‌کند (فقط برای Build اینترنت لازم است؛ خود برنامه آفلاین است).

## فرمان‌های Build و تست

```bash
./gradlew :app:assembleDebug        # ساخت APK دیباگ
./gradlew :app:testDebugUnitTest    # تست‌های واحد
./gradlew :app:lintDebug            # بررسی Lint
```

مسیر APK پس از Build:

```
app/build/outputs/apk/debug/app-debug.apk
```

اگر CI گیت‌هاب اجرا شده باشد، خروجی‌های آماده در پوشه `dist/` همین شاخه قرار می‌گیرند:
`dist/KharjYar-debug.apk` + گزارش Build و تست در `dist/build-report.md`.

## نصب و مجوزها

1. `KharjYar-debug.apk` را به گوشی منتقل و نصب کنید (نصب از منابع ناشناس باید مجاز باشد).
2. برچسب برنامه در نسخه دیباگ «خرج‌یار (نسخه آزمایشی)» است.
3. در صفحه راه‌اندازی اولیه:
   - مجوز **دریافت پیامک** (RECEIVE_SMS) — برای تشخیص خودکار تراکنش‌ها. تاریخچه پیامک خوانده نمی‌شود (READ_SMS درخواست نمی‌شود).
   - مجوز **اعلان** (POST_NOTIFICATIONS) — برای اطلاع‌رسانی تراکنش جدید وقتی برنامه بسته است.
4. هر دو مجوز اختیاری‌اند؛ ثبت دستی بدون مجوز کار می‌کند.
5. وضعیت مجوزها همیشه در «تنظیمات» برنامه قابل مشاهده و درخواست مجدد است.

## محدودیت‌های اعلان و اجرای پس‌زمینه (مهم)

- پس از **Force Stop**، اندروید تحویل Broadcast پیامک را تا اجرای بعدی برنامه متوقف می‌کند.
- برخی سازنده‌ها (شیائومی، هواوی، …) با «بهینه‌سازی باتری» تهاجمی ممکن است دریافت پس‌زمینه را محدود کنند؛ در تنظیمات دستگاه، برنامه را از بهینه‌سازی باتری مستثنا کنید.
- نمایش Heads-up اعلان به تنظیمات دستگاه و کانال اعلان بستگی دارد و تضمین‌شده نیست.
- روی صفحه قفل، جزئیات مالی به‌صورت پیش‌فرض مخفی است (VISIBILITY_PRIVATE).
- برنامه ادعای «دریافت همیشگی و بدون استثنا» ندارد؛ موارد ازدست‌رفته را می‌توان دستی ثبت کرد.

## معرفی حساب و آموزش قالب

1. **حساب جدید:** تنظیمات → مدیریت حساب‌ها → + . عنوان، بانک، رنگ، شناسه ماسک‌شده و سرشماره‌های پیامک را وارد کنید.
2. وقتی پیامک مالی از فرستنده ناشناخته برسد، اعلان «حساب ناشناخته» می‌آید؛ با لمس آن می‌توانید حساب جدید بسازید یا پیامک را به حساب موجود متصل کنید. **همان پیامک اولیه** پس از معرفی دوباره پردازش می‌شود.
3. اگر قالب پیامک شناخته نشود، صفحه «آموزش قالب» باز می‌شود: مبلغ، مانده، شناسه و جهت را از فهرست اعداد/واژه‌های همان پیامک انتخاب کنید. قبل از ذخیره، نتیجه استخراج روی همان نمونه نمایش داده می‌شود.
4. چند قالب برای یک بانک/فرستنده (برداشت، واریز، خرید) پشتیبانی می‌شود؛ قالب‌ها قابل غیرفعال‌کردن‌اند.

## بکاپ و بازیابی

- تنظیمات → «بکاپ و بازیابی رمزنگاری‌شده».
- یک **رمز عبور مستقل** (غیر از PIN گوشی) انتخاب کنید. **فراموشی رمز = غیرقابل بازیابی بودن بکاپ.**
- محل ذخیره فایل را خودتان انتخاب می‌کنید (SAF؛ مجوز حافظه لازم نیست).
- بازیابی: فایل + رمز → نمایش تعداد حساب‌ها/تراکنش‌ها → تأیید «جایگزینی کامل». فایل خراب یا رمز اشتباه هیچ تغییری در داده فعلی نمی‌دهد.
- بکاپ روی هر گوشی دیگری با همان رمز باز می‌شود (کلید وابسته به دستگاه نیست).
- خروجی PDF رمزنگاری **نشده** و جدا از بکاپ است؛ در نگهداری آن دقت کنید.

## تفاوت Debug و Release

- **Debug:** امضای دیباگ، برچسب «نسخه آزمایشی»، suffix شناسه `ir.kharjyar.app.debug`، بدون minify. برای استفاده شخصی همین کافی است.
- **Release:** نیازمند کلید امضای شخصی شماست. ساخت:
  1. `keytool -genkeypair -v -keystore kharjyar.jks -alias kharjyar -keyalg RSA -keysize 2048 -validity 10000`
  2. مشخصات keystore را در `~/.gradle/gradle.properties` (خارج از مخزن!) قرار دهید و `signingConfig` در `app/build.gradle.kts` اضافه کنید.
  3. `./gradlew :app:assembleRelease`
  - کلید خصوصی و رمزها هرگز داخل مخزن قرار نگیرند.

## حریم خصوصی

- همه پردازش‌ها محلی است؛ برنامه مجوز INTERNET ندارد.
- فقط پیامک‌های مالی ذخیره می‌شوند؛ OTP و پیامک شخصی ذخیره نمی‌شود.
- هیچ متن پیامک یا اطلاعات مالی در Logcat ثبت نمی‌شود.
- بکاپ ابری سیستم اندروید برای داده‌های برنامه غیرفعال است.
- هیچ Analytics، تبلیغ یا سرویس بیرونی وجود ندارد.
